# Fyra Lika – testwebbplats

Publik testwebbplats för Fyra Lika (version 13.1).

Webbplatsen publiceras med GitHub Pages från `main` / `/ (root)`.

`index.html` är spelets webbgränssnitt. `config.js` innehåller endast en tom konfiguration tills Supabase Project URL och publishable/anon key konfigurerats. **Lägg aldrig service_role-nyckel eller annan hemlighet här.**

Utan Supabase-konfiguration använder spelet sina inbyggda exempelpussel för dagens pussel. Det är därför inte en komplett produktionsmiljö än.

Administrationssidan och Supabase Edge Function publiceras inte här.
